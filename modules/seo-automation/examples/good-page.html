How to Validate a Sitemap

Published 15 January 2026.

What is an XML sitemap?

An XML sitemap is a file that lists the URLs on a site you want search engines to discover, with optional metadata such as the last modification date of each page.

How many URLs can a sitemap contain?

A single sitemap can list up to 50,000 URLs and be at most 50 MB uncompressed. Larger sites split URLs across several sitemaps and reference them from a sitemap index.

  • Use absolute URLs.
  • Use W3C datetime values for lastmod.
  • List only canonical, indexable URLs.

See the sitemap protocol for the full specification.
