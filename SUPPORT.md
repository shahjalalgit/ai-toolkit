# Support

AI Toolkit is maintained on a best-effort basis. There is no commercial
support or SLA.

## Before asking

1. Run `./scripts/validate-repo.sh` and read any error messages.
2. Check [docs/troubleshooting.md](docs/troubleshooting.md) and
   [docs/faq.md](docs/faq.md).
3. Check the Troubleshooting section of the module's README.
4. Search existing issues.

## Getting help

| Need | Where |
| --- | --- |
| Bug in a module or the installer | Open a **Bug report** issue |
| Improvement idea | Open a **Feature request** issue |
| New module idea | Open a **New automation / module proposal** issue |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md), never a public issue |

Include the command you ran, its full output (with secrets removed), your OS,
`node --version` and the commit hash.
